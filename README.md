# Aurora Galleria — Store Directory

A single-file shopping mall directory page: all 24 stores with full details, live search, category and floor filters, saved stores, and a floor guide.

## Features

- **24 store profiles** — category, unit, floor, phone, hours, website, year established, unit size, description, tags, offers and services
- **Live filtering** — search across names, descriptions, tags and units; 9 category chips with counts; floor selector; sorting by A–Z, level or category
- **Store detail modal** — full profile, current offers, save store and directions
- **Saved stores** — persisted in `localStorage`, with a dedicated filter view
- **Live open/closed status** per store, computed from its own opening hours
- **Floor guide** listing every store by level with unit numbers
- Responsive layout, keyboard shortcuts (`/` to search, `Esc` to close), reduced-motion support

## Run

Open `index.html` in a browser. No build step, server or dependencies required.
